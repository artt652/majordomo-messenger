# Majordomo Message — Android WebView

Проект Android-приложения с нативной панелью навигации и одним основным WebView. Внешний сайт открывается в том же WebView, без iframe и без отдельного окна.

## Реализовано
- Стартовая страница с адресной строкой.
- Кнопки назад, вперёд, обновить, домой.
- История (до 100 адресов) и закладки, сохраняемые локально.
- Cookies, включая third-party cookies, и DOM Storage.
- Разрешения камеры и микрофона запрашиваются, когда их требует сайт.
- Выбор файлов через системный picker и загрузка файлов через DownloadManager.
- Масштабирование жестами.

## Собрать APK в облаке без Android Studio
1. Создайте пустой репозиторий GitHub: https://github.com/new
2. Распакуйте архив и загрузите в репозиторий всё содержимое папки `MajordomoMessage` (включая скрытую папку `.github`). Через браузер GitHub выберите **Add file → Upload files**, затем Commit changes в ветку `main`.
3. Откройте вкладку **Actions**. Выберите workflow **Build Android APK** и нажмите **Run workflow**. При первом запуске разрешите GitHub Actions, если он попросит.
4. Дождитесь зелёного статуса. Откройте запуск и скачайте artifact `MajordomoMessage-debug-apk` внизу страницы.
5. Распакуйте скачанный ZIP и установите `app-debug.apk` на телефон. Android может попросить разрешить установку из браузера или файлового менеджера.

Workflow автоматически запускается также при push в `main`.

## Первый запуск
Введите URL вашего сервера Majordomo в адресную строку и нажмите «Открыть». Адрес сервера намеренно не зашит в проект, так как он зависит от вашей установки.

## Сборка
- Package: `com.majordomo.messenger`
- Min SDK: 23 (Android 6.0+)
- Target/Compile SDK: 35
- JDK: 17
- Для облачной сборки Android Studio не требуется.

## Примечания
- В текущей среде APK не собирался; успешность сборки нужно подтвердить запуском GitHub Actions.
- `usesCleartextTraffic=true` оставлен для совместимости с локальными HTTP-серверами. Для публичной эксплуатации лучше использовать HTTPS и отключить cleartext.
- Разрешение third-party cookies включено ради совместимости, но конкретный сайт может иметь собственные требования к cookies и авторизации.
- Геолокация не включена. Камера и микрофон разрешаются только по запросу сайта и после системного разрешения пользователя.
- Workflow выпускает debug APK, подписанный временным debug-ключом. Для распространения как production-приложения нужна отдельная release-подпись.
